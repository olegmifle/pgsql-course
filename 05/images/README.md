# Образ для стенда домашнего задания 5

Compose использует `postgres:18.4-alpine`. Образ не включён в пакет. Если его ещё нет, Docker загрузит его при первом запуске.

Для компьютера без интернета заранее сохраните образ:

```sh
docker pull postgres:18.4-alpine
docker save -o postgres-18.4-alpine.tar postgres:18.4-alpine
```

Передайте архив отдельно и загрузите на компьютере студента:

```sh
docker load -i postgres-18.4-alpine.tar
```

Архитектура образа должна соответствовать компьютеру получателя. Версию сервера можно узнать через `SELECT version();`.
