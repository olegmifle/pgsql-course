# Домашнее задание 9. Показания датчиков

Посчитайте нагрузку и размер базы, выберите схему хранения и маршруты чтения, настройте репликацию и проверьте её поведение при задержке и остановке узла.

Начните с [гида](homework.md). Его также можно открыть в [PDF](homework.pdf). Ориентир после установки Docker: 2-3 часа.

Нужны Docker с Compose v2 и терминал с `sh`. На Windows команды можно выполнять в WSL с доступом к Docker. Локальный PostgreSQL, Python и дополнительные данные не нужны. Для первого запуска нужен доступ к Docker Hub.

| Файл | Для чего |
| --- | --- |
| [homework.md](homework.md) | Условие и порядок работы |
| [schema.sql](schema.sql) | Место для вашей таблицы и индексов |
| [lab.sh](lab.sh), [compose.yaml](compose.yaml) | Запуск двух PostgreSQL и команды экспериментов |
| [seed.sql](seed.sql) | Небольшой набор показаний |
| [inspect.sql](inspect.sql) | Замеры размеров |
| [status-primary.sql](status-primary.sql), [status-replica.sql](status-replica.sql) | Состояние репликации |
| [report-template.md](report-template.md) | Шаблон результата |

Все команды выполняются из папки с `lab.sh`:

```sh
docker compose version
sh lab.sh up
```

Дальше создайте таблицу и следуйте гиду. Команда запуска сама таблицу не создаёт. У PostgreSQL 18.4-alpine здесь два отдельных тома, до 768 MiB RAM на каждый контейнер, порты компьютера не публикуются. Для Docker выделите около 3 GB памяти и 2 GB свободного места.

Стенд использует проект `pg09-telemetry`. Для другого имени задайте `PG09_PROJECT_NAME` перед началом работы и сохраняйте его во всех терминалах. При необходимости выберите Docker-контекст через `DOCKER_CONTEXT`; глобальный контекст менять не требуется.

```sh
export PG09_PROJECT_NAME=pg09-telemetry-myname
# Только если ваш Docker использует такой контекст:
# export DOCKER_CONTEXT=colima
```

Учебные пароли находятся в файлах пакета. PostgreSQL доступен из контейнеров этого стенда; подключайтесь через `sh lab.sh sql-primary` и `sh lab.sh sql-replica`.

Остановить стенд с сохранением данных: `sh lab.sh down`. Удалить стенд вместе с его учебными данными: `sh lab.sh reset`.
